專案介紹

核心設計理念與整體定位。

本專案是一個常駐型 Twitch 聊天機器人，透過 twitchio 監聽 IRC 聊天訊息、 透過 twitchAPI 的 EventSub WebSocket 接收忠誠點數兌換事件， 並以 Helix API 執行 VIP 授予與移除。

架構上最大的特色是「Bot 主程式 + 本地微服務」的拆分： Google Sheets、OpenAI、MongoDB Atlas、YouTube 四種外部資源都不直接在 Bot 內呼叫， 而是各自由一個本地 HTTP 服務代理，Bot 端僅保留輕量的 HTTP Client（svc_client 套件）。 這讓外部依賴的憑證與 SDK 版本可以獨立於 Bot 演進。

第二個特色是「Google Sheets 作為 CMS」： 指令觸發詞、回覆內容、轉職表、食物清單、諧音梗等營運內容全部放在試算表， 指令派發器（command_dispatcher）依表格設定動態載入對應的 Python 函數， 新增指令不需要動到程式碼。
